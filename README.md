# 跑Online小助手 (Tales Runner Bot) v6.3.3

  
**版本:** v6.3.3 - 跑Online小助手 (加入 `!map` 遠端開關地圖指令版)

---

## 🛠️ 核心功能模組

### 1. 🛡️ 系統安全與授權防護機制
* **系統管理員權限檢查：** 程式啟動時會自動檢測是否以「系統管理員」身份執行，若不是則會彈出警告並終止。
* **雲端授權白名單 (HWID)：** 讀取本機硬件碼並連線到 GitHub 雲端白名單進行校驗。
* **雙 Webhook 隔離防護：** 未授權用戶嘗試運行會自動發送警報並攔截。

### 2. 🎮 自動跑步整合
* 支援整合自動跑步掛機。
* 可透過 UI 或 Discord 遠端指令（如 `!pause`、`!resume`）控制。

### 3. 🤖 AI 智能驗證碼防護
* **自動環境檢查：** 自動檢測並下載安裝 AI 模型。
* **全自動模式：** 自動截圖、AI 辨識及投票輸入驗證碼，並回傳截圖。
* **半自動模式：** 截圖發送到 Discord，用戶可在聊天室手動回覆數字。

### 4. 🧪 遠端自動使用經驗藥水
* 支援 Discord 遠端指令（如 `!藥水 exp`）自動執行：
  1. 離房 ➡️ 大廳 ➡️ 我的房間
  2. 自動搜尋指定藥水並點擊使用
  3. 完成後返回大廳並發送截圖

### 5. 🗺️ 遠端地圖與狀態控制指令
* 支援 Discord 指令開關自動點擊地圖：
  * `!map` / `!map on` / `!map off`
  * `!status`：即時回報目前程式狀態及截圖
